# AI Smart Hal Management System

## About

AI Smart Hal Management System is a web and mobile-based decision support system developed for wholesale fruit and vegetable markets.

The system helps the wholesale market manager monitor producers, commission agents, traders, products, sales, documents and reports from a single platform.

The project also includes AI-powered modules such as:

- OCR-based document analysis
- Price prediction
- Smart dashboard

## Technologies

- ASP.NET Core
- PostgreSQL
- Entity Framework Core
- Kotlin
- Jetpack Compose
- Python
- FastAPI
